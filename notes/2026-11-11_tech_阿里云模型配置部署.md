# 阿里云模型配置与会话选择部署

## 📦 目标

将本地千问型号配置和会话内模型选择部署到既有 AgentFlow，保留真实元数据、模拟数据查询和会话历史。

## 📖 讲透

类似将 ETL 新版本部署到独立目录，再切换作业入口。服务器真实元数据目录只读，模型配置改存现有可写会话数据库，因而能随会话在线备份。

## 🔧 选型

本次发布为基于 a304b94 的未提交工作区快照，不冒充 Git 提交；代码与前端均含逐文件摘要。保留旧版本目录作为回退，不改服务器的环境配置或 Nginx 站点。

## 💡 可迁移

上线前分别核对写权限、配置路径、既有数据及备份覆盖范围；不能仅凭本地测试通过就认定线上可写。

## ⚠️ 常见坑

- 服务器查到的仍是按真实元数据生成的模拟数据，不是业务数据。
- 本次未验证真实模型生成质量或浏览器交互，需用户登录后实际测试。
- 普通 Git 提交发布和回退工具以 `git-<SHA>` 为约定，本次工作区快照需按服务器记录的旧版本路径切换回退；不能直接将快照当作 Git 提交。
