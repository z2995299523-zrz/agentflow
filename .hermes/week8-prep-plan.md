## Day 0: async/await 异步编程讲解

### 为什么必须讲
- FastAPI 是异步框架，写着 `async def`、`await`，不理解就永远在黑盒里改代码
- 面试中几乎必问："你项目中怎么处理并发的？"
- 张润泽以前写的 Python 脚本是同步的，这是知识盲区

### 讲解内容
1. 同步 vs 异步：饭店点餐类比（同步=排队等，异步=拿号先干别的）
2. 事件循环（Event Loop）：单线程凭什么能"同时"处理多个请求
3. `async def` / `await` 语法：不是多线程，是协作式调度
4. 和 ETL 的类比：同步=单表串行抽取，异步=多表并行抽取
5. FastAPI 里的体现：`async def endpoint()` 为什么快
6. 常见坑：在 async 函数里调同步阻塞代码、忘记 await
7. 面试话术：30秒版 + 3分钟版

## Day 0: 错误处理打磨

### 当前状态
- 有 try/except 但偏粗粒度，很多异常直接 500 抛给用户
- 没有统一的错误响应格式
- 没有日志记录

### 要做的
1. 统一错误响应模型（ErrorResponse Pydantic）
2. 主要端点的错误场景补齐：
   - RAG 上传：文件过大、格式不支持、空文件、损坏文件
   - RAG 查询：知识库为空（已做）、LLM 超时、embedding 失败
   - SQL 查询：LLM 生成非法 SQL、数据库连接断开、查询超时
   - LangGraph：某个节点崩溃不影响整体
3. 添加日志（Python logging，至少记录错误级别）
4. 面试话术："你怎么处理异常情况的？"
